# Page Inbox(网页稍后处理)

一个无需构建的 Chrome / Microsoft Edge 轻量扩展:把网页一键存进本地收集箱,稍后打标签、批量整理、导出备份;还可以勾选几篇收藏,让 AI 抓取正文、以对话形式配图讲解。

- **数据全程本地**:保存在浏览器 `chrome.storage.local`,无账号、无遥测
- **零构建、零运行时依赖**:纯 HTML/CSS/JS,唯一内置的第三方库是渲染图表用的 mermaid(本地打包、按需加载)
- **中英双语**界面

## 功能

### 保存与整理(popup)

- 一键保存当前网页;右键菜单保存页面 / 链接;手动粘贴链接
- **全局快捷键**:默认 `Alt + S` 无论在任何网页免打开弹窗一键保存,伴随图标角标即时反馈
- **待办角标与已存感知**:图标实时显示未处理计数;浏览已存网页时角标自动高亮呈现 `✓`,弹窗内指示已在收集箱
- 标签、备注、**置顶**;待处理 / 已处理队列
- **批量管理**:多选后批量添加标签、标记完成、删除,支持全选
- 按标题 / 描述 / 链接 / 备注 / 标签搜索,状态与标签过滤
- 单条复制 Markdown 链接与「📖 纯净阅读」一键直达

### 极简纯净阅读模式 (Reader Mode)

- **免分心纯净排版**:基于智能正文抽取（剔除广告、浮动横幅与侧边栏），以极简排版专注呈现文章主体
- **视觉与排版定制**:支持字号步进调节（A- / A+，14px ~ 26px）、字体风格（无衬线 / 衬线 / 等宽）、页面宽度（紧凑 / 适中 / 宽屏）
- **多套舒适主题**:提供明亮白底、羊皮纸护眼（Sepia）、深灰暗黑与 OLED 纯黑 4 套专属配色，自动记忆用户偏好
- **全流程便捷交互**:自动计算字数与预计阅读时间，支持侧边栏抽屉快速切换其他收藏文章、复制正文纯文本、切换已读/未读状态与直达原网页
- **多端入口随时开启**:在 Popup 条目操作栏、更多功能（Dashboard）卡片与稍后阅读文章列表中均可一键进入

### 原生侧边栏模式 (Side Panel)

- **边看边理不失焦**:基于浏览器原生 `sidePanel` API，摆脱浮窗点击其他区域即关闭的限制；支持左键点击条目直接在当前活动标签页快速查阅，无需新建几十个标签页，边翻看网页、边打勾归档体验绝佳
- **全局快捷键一键唤起**:默认快捷键 `Alt + B` 在任何网页无需找图标，一键瞬间呼出侧边栏
- **支持默认侧边栏打开**:可在侧边栏顶部一键设置“点击扩展图标直接打开侧边栏”，免除弹窗过渡
- **活动标签页实时感知**:长驻侧边栏自动监听标签页切换与地址变更，实时感知当前浏览页面并高亮列表中对应条目，动态更新保存状态
- **全高度流式响应**:100vh 高度弹性占满，随侧边栏拖拽自适应宽度与滚动，长列表容纳更多内容
- **多端便捷唤起**:Popup 顶部栏「◨ 侧边栏」按钮、网页右键菜单“在侧边栏打开稍后处理”或更多功能页一键开启

### 防积压机制：随机回顾与陈年旧藏 (Serendipity)

- **打破“只存不看”的积压死循环**:收集箱进得快出得慢，底部旧文章往往被永久遗忘。新增防积压机制盘活沉睡历史资产
- **🎲 随手读一篇 (Popup / 侧边栏)**:顶部一键掷骰子抽选未读旧藏，动态展示“已沉睡 X 天”徽章，直接提供「📖 纯净阅读」、「↗ 立即查阅」、「✅ 归档」与「🎲 换一篇」
- **列表定位与高亮脉冲**:抽中文章时在收集箱列表中自动滚动并伴随呼吸高亮光晕，一目了然
- **陈年旧藏灵感专区 (Dashboard)**:自动统计超 30 天未读文章数量与积压占比，智能推荐沉底已久的陈年旧藏，支持一键抽换与归档整理

### 更多功能页(独立扩展页)

- **统计概览**:全部 / 待处理 / 已处理 / 置顶 / 近 7 天保存,标签与站点 Top 5,存储占用
- **稍后阅读文章列表**:在独立大屏页面直接检索、筛选已存文章，并一键进入纯净阅读或切换处理状态
- **纯净阅读与 AI 入口**:一键打开极简纯净阅读器或 AI 分析助手
- **导入 JSON** 备份,按链接去重合并
- **导出**:JSON、Markdown、CSV(带 BOM)、Netscape HTML 书签(可直接导入浏览器);一键复制全部为 Markdown

### AI 分析(可选,默认不发起任何请求)

- 左侧列表勾选一个或多个收藏(可搜索),右侧对话式提问
- AI 基于**抓取到的网页正文**讲解分析:优先直接抓取;失败或内容为空时,自动在后台临时打开该网页读取渲染后的内容并关闭(需按站点授权,可读取需要登录的页面)
- 回复以 **Markdown** 渲染,支持 **Mermaid 图表**(流程图 / 时序图等,本地渲染)
- 对话历史保存在本地,可切换、新建、删除
- 接入方式二选一:
  - **浏览器内置模型**(Chrome Prompt API / Gemini Nano):本地推理、数据不出本机
  - **自定义 OpenAI 兼容接口**:填入接口地址 + API Key + 模型名(DeepSeek、通义、Kimi 等均兼容);仅按该域名申请可选权限

## 隐私与权限

- 收藏数据、AI 设置、对话历史均只存本地;抓取的网页正文仅内存缓存,不落盘
- 只有在用户主动配置了自定义接口后,所选网页的标题、链接、描述、笔记和正文才会发往该接口;使用内置模型时数据不出本机
- 必需权限:`activeTab`、`contextMenus`、`scripting`、`storage`、`tabs`(`tabs` 用于读取当前标签页 URL 以判断该页是否已在收集箱、显示角标 ✓ 高亮);可选权限 `https://*/*`、`http://*/*` 仅在 AI 分析时按站点运行时申请
- 完整的商店审核说明(单一用途、权限理由、数据披露、测试步骤)见 [EDGE_SUBMISSION.md](EDGE_SUBMISSION.md)

## 安装(开发者模式)

1. 打开 Chrome 或 Edge 的扩展管理页,开启「开发者模式」
2. 选择「加载已解压的扩展程序」,选中本仓库目录
3. 点击工具栏图标开始使用;AI 功能入口在「更多功能 → AI 助手」

### 配置 AI(可选)

打开「更多功能 → AI 分析 → AI 设置」:

- 接入方式选「自动」:在支持内置模型的浏览器上直接可用
- 或选「自定义接口」,填入兼容 OpenAI Chat Completions 的完整接口地址、API Key 与模型名(如 `deepseek-chat`),保存并允许对应域名权限

## 技术说明

- Manifest V3;不加载、不执行任何远程代码
- 声明权限:`activeTab`、`contextMenus`、`scripting`、`sidePanel`、`storage`、`tabs`;可选权限:`https://*/*`、`http://*/*`
- 目录结构:
  - `popup.*`:弹出主界面(保存与整理)
  - `sidepanel.*`:浏览器侧边栏模式界面(边看边理、标签页实时感知)
  - `dashboard.*`:更多功能页(统计、导入导出与文章列表)
  - `reader.*`:极简纯净阅读模式页(沉浸式阅读、字号调节与暗黑主题)
  - `ai.*`:AI 分析页(列表选择、对话、Mermaid 渲染)
  - `extractor.js`:页面正文提取与解析共享模块
  - `background.js`:右键菜单与后台保存
  - `shared.js`:页面与后台共享的工具函数
  - `mermaid.min.js`:内置图表渲染库(懒加载)
