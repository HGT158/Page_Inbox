# 网页稍后处理

一个无需构建的 Chrome / Microsoft Edge 轻量扩展，用来把网页链接保存到本地收集箱，之后再分类、标记、导出或清理。

## 功能

- 一键保存当前网页
- 抓取页面标题和描述
- 右键菜单保存当前页面或链接
- 手动粘贴链接
- 给链接添加标签和备注
- 置顶重要条目
- 批量管理：多选后批量添加标签、标记完成或删除
- 待处理 / 已处理队列
- 搜索标题、描述、链接、备注和标签
- 一键复制 Markdown 链接
- 导出 JSON 或 Markdown
- 清理已处理条目
- 「更多功能」页面：统计概览、导入 JSON 备份、导出 CSV / HTML 书签、一键复制全部 Markdown
- 「AI 分析」页面：列表勾选收藏的网页，AI 抓取网页正文后以对话形式讲解分析；回复以 Markdown 渲染并支持 Mermaid 图表；对话历史保存在本地、可切换和删除（优先浏览器内置本地模型，也可配置 OpenAI 兼容接口）
- 支持扩展界面与元数据本地化

## 技术说明

- 基于 Manifest V3
- 数据仅保存在浏览器本地的 `chrome.storage.local`
- 不加载或执行远程代码
- 不向服务器传输保存的数据；「AI 分析」为例外：只有在用户主动配置了自定义接口时，所选网页的标题、链接、描述、笔记、标签和抓取的网页正文才会发送到该接口（需用户授予对应域名权限）。使用浏览器内置模型时数据不出本机
- 「AI 分析」抓取网页正文需按站点授予可选权限（`optional_host_permissions`），提取的正文只缓存在内存中供当次对话使用，不会写入存储；直接抓取失败或内容为空时，会在后台临时打开该网页（使用浏览器当前登录会话）读取渲染后的文本并自动关闭标签页
- AI 对话历史保存在本地 `chrome.storage.local`（只含提问与回复，不含抓取的网页正文），最多保留 30 个对话，可在页面内删除
- 当前声明权限：`activeTab`、`contextMenus`、`scripting`、`storage`；可选权限：`https://*/*`、`http://*/*`（仅用于 AI 分析的网页正文抓取和用户配置的接口域名）

## 安装

1. 打开 Chrome 或 Microsoft Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展”。
4. 选择这个文件夹：`C:\Page_Inbox`
